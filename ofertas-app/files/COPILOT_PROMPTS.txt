## PROMPT 1: Crear estructura del proyecto Angular

```
Crea la estructura completa de un proyecto Angular 17+ para una aplicación web
de comparación de ofertas con las siguientes características:

- Usar standalone components (sin NgModules)
- Integrar Angular Material para componentes UI
- Configurar Tailwind CSS para estilos personalizados
- Crear estructura de carpetas con:
  * components/ (search-bar, offer-card, map-view, store-list)
  * pages/ (home, results, product-detail)
  * services/ (products, geolocation, api)
  * models/ (product, offer, store)
  * guards/ para protección de rutas
- Configurar routing con lazy loading
- Configurar environments para dev/prod
- Incluir interceptors HTTP para manejo de errores y autenticación
```
